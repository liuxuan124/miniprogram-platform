WARM CONTENT PLATFORM · PROTOTYPE V1

暖阁 · 内容平台小程序原型

暖色系内容平台：图文长文、小红书式笔记瀑布流、星球社群与话题预测、付费专栏。共 9 个页面，卡片可点击互相跳转。

🎨 主色 #C2410C 砖橘 / #B45309 陶土金 📄 纸感底 #FDF6EC ✍️ 衬线标题 + 无衬线正文 📱 390×844
内容生产阶段 · 阶段一（当前）

内容全部由运营团队产出，署名收敛为三类官方身份：墨白 · 主理人 / 暖阁编辑部 · 官方 / 小满、老陈 · 特约作者。 普通用户在这一阶段可以读、评论、收藏、在星球提问与打卡，但没有开放发布权限——「投稿 / 成为创作者」入口以招募形态保留在发现页与个人中心。 UGC 的数据结构与页面形态（笔记瀑布流、动态流、九宫格、评论盖楼）已经全部预留，阶段二放开权限时无需改版，只需开权限与增加发布器。

一、主框架（底部 Tab 五页）

首页聚合 · 发现瀑布流 · 星球社群 · 商城 · 个人中心

首页home.html ↗问候栏 / 金刚区 / 官方作者矩阵（含投稿招募位）/ 今日精选 / 专栏横滑 / 星球卡 / 混合内容流
笔记（发现）discover.html ↗小红书式双列瀑布流，作者均为官方矩阵；顶部创作者招募条 + 右下角「投稿」次级入口
星球planet.html ↗官方更新 / 精华 / 读者提问 / 读者打卡；话题热度预测；悬浮按钮是「提问·打卡」而非「发布」
商城shop.html ↗虚拟商品为主：电子书 / 资料包 / 专栏课 / 星球年卡 / 实物周边
我的mine.html ↗会员卡 / 快捷入口（消息→notice.html）/ 继续学习 / 我的星球 / 提问与打卡
消息notice.html ↗站内通知列表：支付开通 / 星球回复 / 发货 / 会员到期

二、内容详情（三种内容形态）

同一平台承载三类内容：深度长文、小红书笔记、星球讨论

图文长文详情article.html ↗沉浸封面 / 引言 / 小标题 / 引用 / 配图 / 会员付费墙 / 相关阅读
小红书式笔记详情note.html ↗顶部作者栏 / 图片轮播 / 话题标签 / 带货卡 / 评论盖楼
星球动态详情planet-post.html ↗提问正文 / 星主精华回答 / 点赞头像墙 / 球友讨论

三、列表与商业化

多种内容排版样式集合，以及付费专栏转化页

内容列表list.html ↗热读榜 / 大图卡 / 左文右图 / 音频波形卡 / 九宫格 / 星球内容卡
专栏详情column.html ↗课程封面 / 早鸟倒计时 / 讲师 / 卖点 / 目录试听 / 学员评价 / 购买栏

四、下单与支付（虚拟商品四态）

确认订单 → 微信收银台 → 支付成功 → 订单详情。虚拟商品无收货地址，支付成功即开通权限

下单支付全流程order.html ↗会员省钱提示 / 券与暖豆抵扣 / 不退款协议勾选 ‖ 微信收银台 ‖ 成功页解锁清单 + 邀请有礼 + 进群 ‖ 订单详情含交易单号与退款说明

五、商城与虚拟商品

已提升为底部 Tab 一级入口。电子书、资料包、专栏课、星球年卡、实物周边同台售卖，虚拟商品走「支付即开通阅读权限」而非发货

商城首页shop.html ↗会员条 / 五类目 / 限时特惠倒计时 / 新书首发位 / 商品双列（每件标注格式与会员价）
电子书详情goods.html ↗立体书封 / 会员价 / 虚拟商品交付说明 / 免费试读（范围后台可配）/ 目录锁态 / 不退款提示

六、资料库会员墙（左＝非会员，右＝会员）

非会员默认可看每份资料的前 2 页 / 20%；后台可对单份资料改成「前 N 页」「前 N%」「仅首页」「完全不可见」，也可整类设为免费

资料库列表resources.html ↗会员状态条 / 试读策略说明 / 每份资料标注可看范围 ‖ 会员态：全部解锁、可转发保存

七、资料文件预览（含权限两态）

微信小程序内没有「下载到本地」的落点：附件只能 wx.downloadFile 后用 wx.openDocument 在线预览，留存靠「转发给朋友」。星球动态里的附件卡已改为「预览 ›」。左＝已解锁，右＝非会员

文件预览file-preview.html ↗文件头 / 来源溯源 / 打开进度 / 分页纸张 / 转发保存提示 ‖ 未解锁态：首页模糊 + 入会引导

八、加入社群与客服

三条触达路径并存：小程序内在线客服（无需加好友）、企微客服好友、微信读者群（按方向分群、满员开新群、群码 7 天轮换）

加入社群join.html ↗三种加入方式 / 按方向分群含满员态 / 常见问题 / 防诈提示 ‖ 右：群二维码弹层，长按识别或存相册
在线客服会话service-chat.html ↗快捷问题 / 发送订单卡片 / 图片凭证 / 解决后引导进群

九、分享与邀请

小程序没有可复制的网页链接，所以分享只有两条路：转发卡片给好友/群，或生成带小程序码的海报去朋友圈。分享链路里挂了邀请奖励

分享面板 + 海报share.html ↗左：半屏面板（微信好友带邀请码 / 朋友圈需生成图 / 生成海报 / 发到读者群 + 邀请战绩条）‖ 右：海报（封面款·金句款·纯文字三种模板、专属小程序码、保存相册或直接发送）

十、投稿与发布（UGC 两个阶段）

左＝阶段一「申请成为创作者」，右＝阶段二放开权限后的发布编辑器，形态已备好，到时开权限即可上线

投稿 / 发布contribute.html ↗招募说明 / 方向与形态多选 / 代表作上传 ‖ 编辑器：三种内容类型 / 图片九宫格 / 话题定位关联 / 同步星球 / 仅会员可见

十一、异常与空状态（六态）

建议做成公共组件而非逐页实现。其中「支付失败」必须区分未支付、已扣款未开通、重复支付三种情形，否则客服会被淹没

状态集合states.html ↗合规登录弹层 / 骨架屏 / 无网络 / 空列表 / 支付失败 / 内容下架，每态下方附设计说明

十二、运营后台配置

把「非会员能看多少」「商品怎么交付」「会员有什么权益」全部做成后台可配，避免每次调整都要改代码发版

后台原型（三屏）admin.html ↗① 资料试读配置（preview_mode 字段与端上效果预览）② 商品管理与虚拟商品交付设置 ③ 会员权益开关、内容审核队列、创作者申请

十三、Agent 与知识库（阶段一：仅后台）

Agent 不向用户开放，只作为运营团队的生产工具。四个概念组合出可控的智能体：身份决定它像谁、知识库决定它知道什么、触发场景决定它在哪被调用、发布卡点决定它能不能直接对外

Agent 与知识库后台（四屏）admin-agent.html ↗① Agent 列表与前端开放开关 ② 单个 Agent 配置（身份 / 可读知识库与引用策略 / 触发场景 / 发布链路与限额）③ 知识库管理（自动同步规则、引用策略、切片设置）④ 草稿箱人工确认卡点
