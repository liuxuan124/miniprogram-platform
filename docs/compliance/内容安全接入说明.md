# 内容安全接入说明

**官方资料查阅日期：2026-09-24**

## 官方 API

| 能力 | 文档 | 调用位置 |
|------|------|----------|
| 文本 `msgSecCheck` v2 | https://developers.weixin.qq.com/miniprogram/dev/server/API/sec-center/sec-check/api_msgseccheck.html | **服务端** |
| 图片/音频 `mediaCheckAsync` v2 | https://developers.weixin.qq.com/miniprogram/dev/server/API/sec-center/sec-check/api_mediacheckasync.html | **服务端**异步 + 事件 `wxa_media_check` |
| 内容安全解决方案（总述） | https://developers.weixin.qq.com/miniprogram/security/content/security | 策略说明 |

参数要点：

- `version=2`，`scene`：1 资料 / 2 评论 / 3 论坛 / 4 社交日志
- `openid` 必填（用户近 2 小时需访问过小程序）；无 openid 时**不得**默认放行发布内容
- 文本结果 `suggest`：`pass` / `review` / `risky`（以文档为准）

## 本平台策略（fail-closed）

| 结果 | 发布/评论行为 |
|------|----------------|
| pass | 允许发布（仍保留敏感词 `auto_blocked`） |
| review / 超时 / API 非 0 且非明确 pass | **待人审**（作者可见，公域不可见） |
| risky / 87014 等明确违规 | **拒绝**并记录原因 |

禁止：API 失败时自动当作 pass 发布（fail-open）。

## 与现有模块

- 敏感词：`/api/v1/admin/audit/rules` → `ContentAuditRulesService`
- 评论：已有 v1 检查，迁移到统一 `WxContentSecurityService` v2
- 审计：`mp_compliance_audit_event` + 内容 `auditStatus`

## 官方测试

- 使用微信文档提供的违规样例文本/图片 URL 在**测试环境**验证（具体样例以文档更新为准）。
- 自测记录写入 `docs/compliance/自测记录.md`。
