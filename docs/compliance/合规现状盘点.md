## 已有能力（可复用）

- **商品类型 / 虚拟判定**：`ProductTypes.VIRTUAL`、`OrderServiceImpl` 履约 `virtual/physical`
- **权益 / 退款**：`PurchaseEntitlementService`、`RefundService`、`trySystemFullRefund`（付费问答 CHANGELOG 已记）
- **审核规则 API**：`/api/v1/admin/audit/rules`、内容 `auditStatus`
- **操作日志**：`OperationLog`、版本操作日志
- **功能模块开关**：`plugins` + `FeatureModuleGuard` + admin 侧栏 `featureModule`
- **微信凭证**：`WxMiniappTokenService`（msgSecCheck 已用）

## 风险项（未闭环前勿宣称合规上线）

1. iOS 虚拟商品仅前端拦截，API 仍可下单并调起 **普通** 微信支付（违规风险）。
2. 内容发布未强制微信内容安全 v2；API/超时策略未统一为「待人审」。
3. 小程序类目、虚拟支付开通状态未入库，审核版与正式版能力未分离。
