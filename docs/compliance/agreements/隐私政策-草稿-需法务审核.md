# 隐私政策（草稿，需法务审核）

版本：draft-2026-09-24

## 1. 我们收集的信息

- 微信 openid、昵称、头像（登录）
- 手机号（绑定后服务通知）
- 订单与支付状态（不含完整银行卡号）
- 内容浏览与互动（评论、收藏，用于产品改进）

## 2. 我们如何使用

- 提供知识付费、会员与资料下载服务
- 合规审计与安全风控
- 经**单独同意**后的邮件营销（如开启）

## 3. 您的权利

- 查询、更正、删除账户（小程序「设置」入口，待产品接好 API）
- 撤回同意（不影响撤回前合法处理）

## 4. 存储与保护

- 敏感字段加密存储；管理端脱敏展示并记操作日志

## 5. 联系我们

- 客服电话/邮箱：由运营在后台「基本设置」填写
