# 运营后台页面搭建与内容发布统一测试及优化说明

> 日期：2026-09-27  
> 模式：QA（运营人员视角的生产环境探索测试）  
> 环境：`https://zfculture.site`，Chrome，超级管理员账号  
> 范围：页面搭建、草稿保存、预览、发布前检查，以及内容概览、长文、笔记、资料、动态、视频、互动和内容设置  
> 结论口径：本报告是专项探索验收，不代表全系统、全角色、真机、支付或并发测试完成。

## 1. 结论摘要

页面和内容的基础能力已经具备：运营人员可以创建页面、组合组件、保存草稿、预览页面，也可以创建长文、配置分类、预览并保存草稿；内容筛选、搜索、卡片视图、SEO、关联商品、资料文件库、审核规则等入口均可访问。

当前不建议把后台交给普通运营人员无保护地直接使用。主要原因不是功能缺失，而是多个页面在路由切换和异步加载期间会展示错误状态，其中内容编辑器存在“地址已切换、编辑器仍保留上一内容类型和未保存输入”的高风险问题，可能导致错类型保存、误修改或误发布。

本轮记录：

- P1：5 项
- P2：8 项
- P3：3 项
- 专项检查点：61 项；PASS 34、FAIL 9、PARTIAL 13、NOT_RUN 5
- 执行率：56/61（91.8%）；通过率：34/61（55.7%）
- 未执行高影响检查：正式发布、上下架、删除/恢复、定时任务实际触发、普通运营权限、并发与重复提交、真机最终展示

上线运营建议：先修复 P1，再由测试账号执行一次“草稿 → 定时 → 发布 → 下架 → 回收站恢复”的闭环回归；在此之前，要求运营每次切换内容类型后刷新页面，并且只通过显式按钮保存草稿。

## 5. 缺陷与优化项

### P1-01 内容编辑器未响应路由参数变化

复现：

1. 进入“资料 → 上传资料”。
2. 再进入“视频 → 发视频”或“笔记 → 写笔记”。
3. 观察地址已变为 `/content/write?type=video` 或 `type=note`。
4. 编辑器仍显示上一类型的标题、字段和预览；只有强制刷新后恢复。

影响：运营可能在“视频”地址下编辑资料，或把上一个内容的本地数据保存到错误类型。

建议：

- 监听路由 `type` 和 `id`，变化时先阻断编辑区、清空旧 store，再加载新模型。
- 为编辑会话增加 `contentType + contentId + sessionId` 隔离键。
- 类型加载完成前显示骨架屏，禁止保存、预览和输入。
- 增加 note→moment、file→video、edit→create 的自动化回归。

### P1-02 未保存内容跨类型残留

笔记输入 21 字标题后点击取消，再进入“发动态”，地址已是 `type=moment`，界面仍保留笔记标题和笔记表单。

建议在取消、关闭标签、路由离开时销毁编辑 store；如果存在修改，应明确询问“放弃修改/继续编辑”，不能依赖页面刷新清理。

### P1-03 页面装修自动保存状态不可信

装修器显示“保存中…”，离开时仍提示存在未保存修改，并出现一次恢复默认内容。显式点击“保存草稿”后才稳定持久化。

建议统一状态机：`未保存 → 保存中 → 已保存（时间）/保存失败`；保存请求结束前禁止离开，失败必须展示重试，不得仅靠模糊的“保存中”。

### P1-04 编辑器路由白屏和返回不同步

- 历史页面 ID 38 打开时出现白屏，控制台报 `Couldn't resolve component "default"`。
- 从装修器返回后，地址已是 `/mini/pages`，但界面仍停在装修器，刷新后才一致。

建议修复懒加载组件导出和路由缓存；增加全局错误边界、重试按钮和“返回页面列表”兜底。

### P1-05 内容更新时间疑似被读取操作改写

进入列表后，多条内容的更新时间统一变为测试当下时间：笔记多数为 `09-27 22:39`，动态前 3 条为 `09-27 22:39`，随后长文多数也变为相同时间。本轮没有编辑这些正式内容。

建议立即审查：

- 列表查询是否调用了 seed/upsert/数据补齐服务。
- ORM 实体读取后是否被脏检查自动提交。
- 内容初始化器是否在每次请求执行并更新 `update_time`。
- 用数据库审计日志对比请求前后 `updated_at`，确认是否真实落库。

若确认读取会写数据，应升级为 P0 并暂停普通运营使用。

### P2-01 异步加载期间展示错误业务状态

内容概览、长文、笔记、动态都会先显示 0 条或“暂无内容”，约 1–2 秒后变成真实数据；保存后还出现过翻倍计数。

建议首次加载使用骨架屏；请求未完成前不得渲染空状态、统计数字或可操作开关；旧页面离场时立即卸载而非与新页面叠加。

### P2-02 草稿详情加载前可以看到空白编辑器

打开已有草稿时，页面先显示空标题、空正文、默认立即发布，随后才回填草稿。如果运营在回填前输入，可能覆盖数据。

建议加载期间禁用所有字段和发布按钮，并以 `hydrated=true` 作为允许编辑的硬门禁。

### P2-04 笔记标题长度只提示、不约束

标注最多 20 字，但允许输入和预览 21 字。应在输入层设置 maxlength，并由服务端再次校验；错误信息应在字段下方明确显示。

### P2-05 视频入口缺少视频上传能力

页面说明为“视频号/外链视频”，字段提示“或上传后的视频 URL”，但只提供 URL 输入。建议增加视频素材库/本地上传，或删除误导文案并明确仅支持外链。

### P2-06 发布操作缺少变更范围确认

页面发布概览已有 1 项站点配置待同步。运营点击“保存并同步”可能把与当前页面无关的既有修改一起发布。

建议发布前展示逐项 diff、来源、修改人、修改时间，并允许只发布指定页面或站点配置。

### P2-07 预览加载时短暂显示错误空态

扫码预览先显示“暂无文章数据”，随后才出现 3 篇真实文章。应改为加载中，只有请求成功且数据确实为空时才展示空态。

### P2-08 页面与内容资产缺少生命周期治理

页面列表共有 43 项、归档 13 项，同时存在“暖阁”“墨太白”等多套页面及名称为 `x` 的页面；内容也存在多个标题高度相似的正式条目。

建议增加“线上使用中”、所属版本/主题、最后发布人、引用入口数、重复内容检测和批量归档。

### P3-01 编辑页出现孤立必填星号

“关联商品”和“SEO 与分享配置”页签顶部出现单独的 `*`，应绑定到真实必填字段或删除。

### P3-02 互动中心直接展示完整手机号

创作者申请列表直接展示完整手机号。建议普通运营默认脱敏，仅拥有敏感信息权限的角色可展开查看，并写入审计日志。

### P3-03 前端组件弃用警告

控制台持续出现 Element Plus `el-checkbox label act as value` 弃用警告。应改用 `value`，避免未来升级后复选框行为变化。

## 6. 推荐整改顺序

### 第一阶段：防止错改与数据污染

1. 修复内容编辑器对 `type/id` 的响应、store 隔离和加载门禁。
2. 核验列表读取是否批量改写 `updated_at`。
3. 修复页面装修器自动保存和路由白屏。
4. 为发布动作增加明确的变更范围确认。

### 第二阶段：统一异步状态

1. 列表、概览、编辑详情统一为 loading / success-empty / success-data / error 四态。
2. 路由切换时立即卸载旧视图，避免旧页面与新页面同时存在。
3. 预览数据加载失败与真实空数据采用不同文案。

### 第三阶段：运营效率与数据治理

1. 清理乱码文件、重复文件、重复内容和废弃页面。
2. 页面和内容列表增加引用关系、线上版本、发布人和修改来源。
3. 补视频上传、内容批量操作和更明确的定时发布状态。
4. 增加普通运营、审核员等角色视角及敏感信息脱敏。

## 7. 修复后的回归清单

- 连续执行 `长文 → 资料 → 视频 → 笔记 → 动态 → 长文编辑`，每次无需刷新且字段不串页。
- 在上一类型输入但不保存，切换后旧输入不得出现在新类型。
- 已有草稿加载完成前字段不可编辑；加载失败提供重试，不显示空白默认表单。
- 只查询列表不得改变任何正式内容的 `updated_at`、作者、状态或排序。
- 页面自动保存需要展示明确时间，刷新和离开后内容一致。
- 页面返回后 URL、侧栏选中项和主视图完全一致。
- 所有列表加载期间不显示 0 条或“暂无内容”。
- 笔记标题前后端均拒绝超过 20 字。
- 文件库中文文件名正常，同一文件不重复登记。

### 10.2 发布阻断项

#### MP-P0-01 生产线上 Tab 与页面绑定错误

生产公开配置 `live_release_no=11` 当前为：

- 首页绑定 `pages/index/index`，线上 DSL 只有 1 个 `rich_text`，正文是“请输入富文本内容是对方是对方……”的占位测试文本；页面背景仍是 `#f5f6f9`。

小程序 Tab 壳会主动读取线上 `tabbarItems` 和 DSL，因此重新上传相同代码不会修复这些问题。必须先在后台纠正线上绑定、占位内容、品牌和背景，再发布新的内容配置版本。

#### MP-P0-02 提审脚本与真实功能不一致

`scripts/submit-miniprogram-audit.js` 存在三类阻断：

- 提审页面仍写旧主包路径 `pages/content-list/content-list`、`pages/tab-hub/tab-hub`，两者都不是当前注册地址。
- 审核说明声称“不含商品交易、会员充值、在线支付与配送功能”，但生产配置已启用 product、member、order，代码也含商城、购物车、订单和支付。
- 类目优先选资讯/教育/工具，与当前商业功能不一致。

这会造成提审失败或申报不实。应根据最终保留的功能、实际类目和页面路径重写提审清单，不得通过关闭校验或伪造说明绕过。

#### MP-P1-01 隐私协议仍处于草稿状态

#### MP-P1-02 活动组件存在确定性死链

### 10.3 需要清理和优化的代码

1. **测试能力进入正式包**：`pages/render-parity/render-parity`、黄金 DSL 和 6 批测试数据仍注册/打入主包。应移出正式 `app.json`，由专用测试构建启用。

3. **全站允许索引**：`sitemap.json` 当前允许索引所有页面，会把登录、状态、测试或工具页一并纳入搜索范围。应只允许公开内容详情/列表，其他页面明确拒绝。
