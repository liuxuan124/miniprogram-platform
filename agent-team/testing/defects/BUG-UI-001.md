# BUG-UI-001

- 编号：`BUG-UI-001`
- 类型：体验问题
- 关联功能点 ID：未分配
- 严重度：P3
- 所属模块与页面：页面管理 / 新建页面
- 指派 Agent：admin-agent
- 指派依据：前端校验提示未随输入清除
- 状态：回归通过
- 复现概率：必现

## 从登录开始的完整复现路径

1. 登录后台 → 关闭强制改密弹窗
2. 左侧「页面管理」→「新建页面」
3. 清空「页面名称」，点「创建并装修」
4. 出现「请输入页面名称」
5. 再输入 50 个「测」（计数显示 50/50）

## 实际现象

名称已填满 50/50，红色「请输入页面名称」仍留在字段下方。随后点「创建并装修」仍能创建成功（校验提示是脏的，未挡住提交）。

## 预期现象及依据

失焦/输入后应清除空值错误；错误提示应与当前字段值一致。

## 影响范围

新建页面表单。会误导操作者以为仍不能提交。
