# BUG-SET-002

- 编号：`BUG-SET-002`
- 类型：配置状态不一致
- 关联功能点 ID：EXP-SETTINGS-WECHAT
- 严重度：P2
- 所属模块与页面：系统设置 / 微信小程序配置 / 订阅消息
- 指派 Agent：admin-agent
- 指派依据：状态列为已启用，模板 ID 为空
- 状态：回归通过
- 复现概率：当前配置必现

## 从登录开始的完整复现路径

1. 登录后打开「微信小程序配置」`/settings/wechat`
2. 滚到「订阅消息与通知配置」

## 实际现象

- 微信支付：关闭（未改开关）
- 订阅消息表：
  - 订单发货通知：**已启用**，模板 ID 空白
  - 活动报名成功：**已启用**，模板 ID 空白
  - 预约提醒：**已启用**，模板 ID 空白
  - 支付成功确认：未配置
  - 优惠券到期提醒：未配置

## 预期现象及依据

「已启用」应表示模板 ID 已填写且可用于下发；无模板 ID 时应为未配置，而不能标已启用。

## 影响范围

订阅消息开关状态不可采信；运营会以为发货/报名/预约通知已接通。
