## 2. Tab / 我的 / 星球：改完会不会立刻影响线上？

### 2.1 底部 Tab（`tabbarItems`）

| 改法 | 是否立刻影响真机用户 |
|------|----------------------|
| 后台 **外观 → 站点草稿**（API `updateSiteDraft`，只写 `site_builder_draft`） | **否**。真机仍读 live 的 `tabbarItems`，直到你在发布流程里 **「上线到小程序」** 触发 `promoteSiteBuilderDraft()`，才把草稿里的 Tab 等写入 live。 |
| 直接改库 / 系统配置批量接口里的 **`tabbarItems`** | **是**。该键在 `RUNTIME_PUBLIC_CONFIG_KEYS` 中，会覆盖发布快照里的 Tab。 |

**结论（按你第 1 条前提）：** 可以在 **站点草稿** 里把「发现」改为「内容」，并绑定到新建页 **「墨太白-内容」**；**不要**直接改 live `tabbarItems`。

**拟定草稿 Tab（待新建页拿到 `pageId` 后写入 `site_builder_draft.tabbarItems`）：**

- 首页：暂仍指向 live `pageId=21`（暖阁首页），发布前你可再改为「墨太白-首页」。
- **发现 → 内容**：`text: "内容"`，`pageName: "墨太白-内容"`，`pageId: <新建页ID>`，`path: /pages/custom/motai-content`（path 以实际建页为准）。
- 星球 / 商城 / 我的：草稿期可继续指向 23–25，或后续改为「墨太白-星球」等 custom 页。

**当前 live Tab 未改**（备份见 `tabbarItems.json`）。

### 2.2 `minePageConfig` / `planet_config`

二者均在 **`RUNTIME_PUBLIC_CONFIG_KEYS`**，写入 `mp_system_config` 后 **下一次拉 `/api/v1/mp/system/config` 即对线上生效**（不经过站点草稿）。

**结论（按你第 3 条）：** **未改** live 的 `minePageConfig`、`planet_config`。只在本报告 **§6** 给出按原型的替换方案，由你在后台改或等绑定「墨太白-我的/星球」custom 页后一并发布。

### 2.3 星球商业化（`mp_planet_commerce_config`）

保存即写库，**立即生效**。当前表 **无配置行**。拟价 **¥365/年（待确认）**、未上架商品：见 **§5**，由你在 **会员/商品/星球商业化** 里建草稿，**全部 off-sale / 未启用**。

## 3. 原生详情页 vs 原型（P3 / P5 / P11）

装修器内 P3/P5/P11 仅作 **说明/模板页**；真机以原生页为准。

### 3.1 P3 文章详情（`pages/content-detail`）

| 原型元素 | 原生支持 | 说明 |
|----------|----------|------|
| 试读 + 渐变遮罩 | ✅ 部分 | 接口 `locked` + 截断正文/图集；标题可展示「剩余 N%」（`content_member_wall.remainPercent`） |
| 付费墙主文案 / 副文案 | ✅ | `content_member_wall.desc`、`memberYearPrice`；已按原型写入 **live**（¥199 为 **待确认** 展示价） |
| 解锁：开通会员 | ✅ | 按钮「开通会员 ¥199/年」→ 会员中心 |
| 解锁：单篇 ¥9.9 | ❌ | 无单篇购买入口；仅「已购专栏？免费解锁」链 `unlockProductId` |
| 解锁：邀请 N 人免费读 | ❌ | 无 UI / 无链路 |
| 解锁：去星球开通 | ⚠️ | 微信长文样式仍有「去星球」；暖阁长文样式走会员按钮为主 |
| 文末 **配套资料区** | ❌ | 原生页无「📎 本文配套资料」列表（资料请从资料库进 `file-preview`） |
| 底部互动条 | ✅ | 赞/收藏/分享/留言（原生，非装修器） |

### 3.2 P5 资料详情（`pages/file-preview`）

| 原型元素 | 原生支持 | 说明 |
|----------|----------|------|

| 权限与锁定 | ✅ | `locked` + 去开通会员 |
